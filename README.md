# لُقمة | LUQMA — Digital Cartoon Front-end

نسخة تصميم Front-end فقط، بدون قاعدة بيانات حاليًا.

## المزايا
- واجهة Digital + Cartoon
- عربي / English
- RTL تلقائي للعربية وLTR للإنجليزية
- Light / Dark Mode
- حفظ اللغة والثيم في localStorage
- Home, Explore, My Day, Profile, Login / Sign Up
- بحث وفلاتر وتفاصيل الأطعمة والكمية كتجربة تصميم

## التشغيل
افتح `index.html` مباشرة أو استخدم VS Code + Live Server.

## المرحلة التالية
بعد اعتماد التصميم نضيف Node.js/Express ثم قاعدة البيانات وتسجيل الدخول والحفظ الفعلي.
